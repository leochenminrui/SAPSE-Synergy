# External corpora

Raw CompCert, Coq/Rocq standard-library, and coq-ext-lib source trees are not
bundled. The supplied fixed-draft evaluation does not need them. See the
[data guide](../README.md) for input provenance, retrieval on user-supplied data,
and the distinction between generated drafts and original theorem statements.

Upstream locations and license notices are listed in
[THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md). The original extraction
scripts and immutable corpus revisions are not supplied, so cloning current
upstream branches does not reconstruct the paper's corpus.
